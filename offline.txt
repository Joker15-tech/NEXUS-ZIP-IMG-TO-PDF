## 🎯 ÉTAPE 2 — Crée le dossier `vendor/` et télécharge les 2 libs

Copie-colle **ce bloc entier** dans PowerShell :

```powershell
# Créer le dossier
mkdir web\vendor -Force | Out-Null

# Télécharger JSZip (~100 KB)
Write-Host "▸ Téléchargement JSZip..." -ForegroundColor Cyan
Invoke-WebRequest `
    -Uri "https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js" `
    -OutFile "web\vendor\jszip.min.js"

# Télécharger jsPDF (~350 KB)
Write-Host "▸ Téléchargement jsPDF..." -ForegroundColor Cyan
Invoke-WebRequest `
    -Uri "https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js" `
    -OutFile "web\vendor\jspdf.umd.min.js"

# Vérifier
Write-Host ""
Write-Host "✓ Fichiers téléchargés :" -ForegroundColor Green
Get-ChildItem web\vendor\ | Format-Table Name, @{Name="Taille";Expression={"{0:N0} KB" -f ($_.Length/1KB)}}
```

**Tu dois voir** :
```
✓ Fichiers téléchargés :

Name                Taille
----                ------
jszip.min.js        97 KB
jspdf.umd.min.js    356 KB
```

## 🎯 ÉTAPE 3 — Modifie `web/index.html`

Ouvre `web/index.html` dans VSCode (ou Notepad).

**Cherche ces 2 lignes** (vers le bas du fichier, avant les `shared/*.js`) :

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/jszip/3.10.1/jszip.min.js"
        crossorigin="anonymous" referrerpolicy="no-referrer"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js"
        crossorigin="anonymous" referrerpolicy="no-referrer"></script>
```

**Remplace-les par** :

```html
<script src="vendor/jszip.min.js"></script>
<script src="vendor/jspdf.umd.min.js"></script>
```

💾 **Sauvegarde.**
